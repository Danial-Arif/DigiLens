# 🔢 DigitLens

**Handwritten Digit Recognition using PyTorch**

DigitLens is a simple Deep Learning project that recognizes handwritten digits (0–9) using a neural network built with PyTorch and trained on the MNIST dataset.

## ✨ Features

- Handwritten digit classification (0–9).
- Built using PyTorch.
- Trained on the MNIST dataset.
- Custom neural network architecture.
- Model evaluation using test accuracy.
- Saved model weights for future predictions.

## 🧠 Tech Stack

- **Python**
- **PyTorch**
- **Torchvision**
- **Matplotlib**
- **MNIST Dataset**

## 📊 Dataset

DigitLens uses the MNIST dataset, which contains:

| Dataset | Images |
|---|---:|
| Training | 60,000 |
| Testing | 10,000 |
| Image Size | 28 × 28 |
| Classes | 10 (0–9) |


## 🎯 Project Goal

The goal of the project is to implement what I've learnt so far and to build a neural network from scratch using a real-world image classification dataset.
